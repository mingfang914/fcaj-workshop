# Summary Report: "FCAJ Intern Meetup 13/6"

### Event Objectives

- Present weekly internship progress, demonstrating the cloud infrastructure and serverless backend setups of the individual Smart Image Platform projects.
- Share career pathways in DevOps, Data Analytics, and AI engineering, introducing multinational corporation (MNC) work cultures and recruitment processes.
- Gather feedback and technical review comments from Mentors to optimize and secure the system architecture.

### Presenters & Reporting Groups

- **Trương Hoàng Trọng** – DevOps Engineer at Endava Vietnam (Topic: "*DevOps Career Pathway & Tools*")
- **Mr. Đạt Phạm** (Data Analytics Engineer) & **Mr. Cường Nguyễn** (Process Engineer) (Topic: "*Data Work & Corporate Culture at MNCs*")
- **Danh Hoàng Hiếu Nghị** – AI Engineer & AWS Community Builder (Topic: "*FCAJ to AWS Partner Journey*")
- **Trung Kiên and Minh Thọ** – Progress Report (Topic: "*Building Secure Application Flows with Cognito, Lambda, and S3*")

### Key Highlights

#### 1. Real-World DevOps Careers (Trương Hoàng Trọng)
- Clarified differences between theoretical Job Descriptions (CI/CD, IaC, K8s) and the daily reality of a DevOps engineer (problem-solving, systems recovery).
- Advised starting with fundamentals (Linux, Networking, Python/Golang, Git, Containers) rather than chasing advanced tools.
- Highlighted core lessons: copying commands does not equal understanding, ask "why" before "how", and communication is a vital part of the job.

#### 2. Storytelling with Data and MNC Culture (Mr. Đạt Phạm & Mr. Cường Nguyễn)
- Explained that a Data Analytics Engineer's role depends heavily on the business domain and department, requiring critical thinking, communication, and problem-solving skills.
- Outlined typical MNC hiring steps: ATS resume screening, English HR screening, technical competency tests, and behavioral interviews.
- Shared career development frameworks and defined corporate culture as the way a company thinks, lives, and works.

#### 3. Transitioning from Student to Partner Engineer (Danh Hoàng Hiếu Nghị)
- Shared personal development milestones: starting as a First Cloud Journey member, leading the AWS Student Builder Group, and being named an AWS Community Builder.
- Discussed preparing technical skills and portfolios to transition successfully from a student builder to an engineer at AWS Partner companies.

#### 4. Technical Progress: Secure App Flow with Cognito, Lambda, and S3 (Trung Kiên and Minh Thọ)
- Reported on integrating Cognito User Pools as an Authorizer to authenticate and secure API Gateway access for React SPAs.
- Presented a secure upload/download flow: replacing public S3 bucket access with temporary, short-term S3 Presigned URLs generated by Lambda backend functions.
- Resolved permission boundaries by applying least-privilege IAM roles and policies to Lambda functions.

### Lessons Learned

- **DevOps Systems Thinking:** Understood that while tools change, fundamentals (Linux, Networking) remain the key to solving infrastructure challenges.
- **MNC Recruitment Mechanics:** Gained clarity on ATS filters, behavioral interviews, and the level of communication required to join multinational companies.
- **Secure Serverless Design:** Mastered the integration of Cognito User Pools and S3 Presigned URLs to prevent public data exposure.

### Applying to Work

- Configured a **Cognito Authorizer** to protect the REST API Gateway endpoints of the Smart Image Platform project.
- Implemented **S3 Presigned URLs** at the Lambda backend for secure, temporary image upload and viewing, closing public S3 access.
- Audited Lambda execution roles to enforce the **Least Privilege** principle by removing wildcard (`*`) permissions.

### Event Experience

- A structured, technical review session that exposed architectural bottlenecks early.
- Career path sharing from senior DevOps, Data, and AI engineers provided clear guidance for subsequent professional growth.
