**This page** contains the internship worklog divided into 12 weeks. The first 8 weeks focus on core AWS Study Group (FCJ) foundational services and labs. The final 4 weeks focus on building and deploying the official project (`AWS-Project`), which is the Smart Image Platform.

The weekly tasks are distributed as follows:

**Week 1:** [Getting familiar with the FCAJ internship program](1.1-Week1/) (17/04/2026 - 19/04/2026)

**Week 2:** [Set up an AWS account, configure cost controls, and practice Identity and Access Management (AWS IAM & MFA)](1.2-Week2/) (20/04/2026 - 26/04/2026)

**Week 3:** [Study and practice Object Storage & Content Delivery Network (S3 & CloudFront)](1.3-Week3/) (27/04/2026 - 03/05/2026)

**Week 4:** [Design cloud network infrastructure (Amazon VPC, subnets, NAT, Bastion Host)](1.4-Week4/) (04/05/2026 - 10/05/2026)

**Week 5:** [Manage cloud databases (Amazon RDS MySQL & DynamoDB)](1.5-Week5/) (11/05/2026 - 17/05/2026)

**Week 6:** [Ensure high availability & scaling (ALB, ASG, Apache Stress Testing)](1.6-Week6/) (18/05/2026 - 24/05/2026)

**Week 7:** [Operations & system monitoring (CloudWatch Alarms, SNS Email, Dashboard)](1.7-Week7/) (25/05/2026 - 31/05/2026)

**Week 8:** [Basic Serverless concepts (AWS Lambda, S3 Event Notification, API Gateway)](1.8-Week8/) (01/06/2026 - 07/06/2026)

**Week 9:** [Official Project: Architecture analysis and access-pattern-driven DynamoDB design](1.9-Week9/) (08/06/2026 - 14/06/2026)

**Week 10:** [Official Project: User Authentication (Cognito) & IAM Security Policies](1.10-Week10/) (15/06/2026 - 21/06/2026)

**Week 11:** [Official Project: Serverless Backend & S3/DynamoDB Stream Triggers Deployment](1.11-Week11/) (22/06/2026 - 28/06/2026)

**Week 12:** [Official Project: Frontend Deployment (Amplify), E2E Testing & Resource Cleanup](1.12-Week12/) (29/06/2026 - 05/07/2026)
